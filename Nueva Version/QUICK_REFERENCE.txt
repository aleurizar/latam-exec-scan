### 📊 FÓRMULAS DE SCORING

#### EMPRESA
```
SCORE_FINAL = (Relevancia × 0.35) + (Confianza × 0.30) + (Contactabilidad × 0.35)

Relevancia = (Ventas_Totales × 0.60) + (MercadoLider × 0.40)
Confianza = (Website × 0.35) + (LinkedIn × 0.25) + (Email × 0.25) + (DataMatch × 0.15)
Contactabilidad = (Email × 0.35) + (Phone × 0.25) + (WhatsApp × 0.25) + (Redes × 0.15)
```

#### CONTACTO
```
SCORE_FINAL = (Seniority × 0.40) + (RelevanciaRol × 0.35) + (Contactabilidad × 0.25)

Seniority: C-level=100 | Director=90 | Manager=75 | Specialist=60 | Other=40
RelevanciaRol: CEO/Founder=100 | Ecom Manager=95 | Ops=80 | ICP=60 | Other=40
Contactabilidad = email_verified + phone + whatsapp + linkedin
```

#### OUTREACH FINAL
```
SCORE_FINAL_OUTREACH = (ContactoScore × 0.60) + (EmpresaScore × 0.40)

Ready to Outreach? = (clasificacion == 'ALTO' OR clasificacion == 'MEDIO')
Canal Recomendado = email_verificado > whatsapp > linkedin > phone
```

### 🚨 GATES (Reglas Bloqueantes)

| Gate ID | Condición | Max Clasificación | Severidad |
|---------|-----------|-------------------|-----------|
| GATE_NO_CANALES | email_corp = NULL AND phone = NULL AND whatsapp = NULL | BAJO | Bloqueante |
| GATE_BAJA_RELEVANCIA | score_relevancia < 30 | BAJO | Media |
| GATE_CONTACTABILIDAD_BAJA | score_contactabilidad < 60 AND score_final >= 80 | MEDIO | Media |

**Cómo aplican:**
1. Se calculan scores dimensionales
2. Se aplican gates
3. Si gate aplica → baja clasificación final
4. Luego se asigna al rango (ALTO/MEDIO/BAJO/BÁSICO)

### 🗄️ TABLAS SUPABASE (YA CREADAS)

```sql
config_motor
├── id BIGINT (PK)
├── version_number INT
├── motor_type VARCHAR
├── config_json JSONB (pesos, gates, umbrales)
├── is_active BOOLEAN
└── created_by UUID

empresa_scores
├── id UUID (PK)
├── empresa_id UUID (FK → companies.id)
├── config_motor_id INT (FK)
├── scores JSONB (relevancia, confianza, contactabilidad, final)
├── clasificacion VARCHAR (ALTO/MEDIO/BAJO/BÁSICO)
├── gates_applied JSONB (qué gates aplicaron)
└── reasoning_json JSONB (explicación)

contacto_scores
├── id UUID (PK)
├── contacto_id UUID (FK → executives.id)
├── empresa_id UUID (FK)
├── scores JSONB (seniority, relevancia_rol, contactabilidad, final)
├── clasificacion VARCHAR
└── gates_applied JSONB

registro_final_outreach
├── id UUID (PK)
├── empresa_id UUID
├── contacto_id_primario UUID
├── score_final_outreach NUMERIC
├── ready_to_outreach BOOLEAN
├── priority_rank INT
├── canal_recomendado VARCHAR (email/whatsapp/linkedin/phone)
├── prepared_for_crm BOOLEAN
└── timestamp TIMESTAMPTZ
```
